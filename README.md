# Automatenplanet

Hier ist ein **sehr ausführlicher Lovable-Prompt**, damit eine KI eine **moderne High-End Website für AutomatPlanet.de** erstellt. Der Prompt enthält **Design, Struktur, Produktseiten, SEO-Texte, Blog, Kategorien, Animationen, Videos, Lead-Formulare und Standort-Keywords**.

---

Create a modern, dynamic and high-converting website for a company called **AutomatPlanet.de**.

AutomatPlanet.de sells and distributes arcade machines and vending entertainment machines across Germany and Europe.

Products include:

* claw machines (Greifautomaten)

* boxing machines (Boxautomaten)

* basketball arcade machines

* classic arcade machines

* prize machines

* coin operated machines

* entertainment vending machines for businesses.

Target customers:

arcade studios, kiosks, spätis, shopping malls, airports, supermarkets, event locations, clubs, amusement parks and entertainment venues.

Design style:

modern tech + arcade aesthetic.

Color palette:

dark background (black / dark blue)

neon arcade accents (purple, blue, pink)

clean white typography.

Visual style:

high-energy arcade environment with LED lighting, animated graphics and large visuals.

Include:

video backgrounds

product slideshows

smooth scrolling animations

hover effects

interactive product cards

modern UI elements.

Goal of the website:

generate machine sales inquiries and position AutomatPlanet.de as the leading arcade machine supplier in Germany.

Homepage hero section:

Background video showing an arcade environment with claw machines, boxing machines and basketball machines in action.

Headline:

“Arcade-Automaten für dein Business”

“Greifautomaten, Boxautomaten, Basketball-Automaten und Arcade-Games für Kioske, Spätis, Arcades, Shoppingcenter und Events.”
